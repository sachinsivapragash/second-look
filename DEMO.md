# Second Look: demo video script (about 2:45)

Record the live site in Chrome at https://sachinsivapragash.github.io/second-look/ (Win+Alt+R records the window with Xbox Game Bar), then upload to YouTube as Unlisted or Public.

| Time | Show | Say |
|---|---|---|
| 0:00–0:15 | Home page | "Scam texts hit older relatives hardest, and the usual fix is pasting private messages into a chatbot. Second Look checks them privately using Firebase AI Logic hybrid inference." |
| 0:15–0:45 | Click **📦 Parcel fee** → **Check it** | "Instant checks run on the device first. Chrome's Gemini Nano isn't ready here, so phone numbers and link paths are removed on the device before Gemini checks the rest in the cloud." Point at the verdict, What to do, Why. |
| 0:45–1:05 | Open the **privacy receipt**, then **Show exactly what was sent** | "The receipt shows exactly what left the device, and what was removed." |
| 1:05–1:25 | **Ask about it** → "I already clicked the link. What now?" | "Follow-up questions get calm, step-by-step help." |
| 1:25–1:45 | Set **Answer in** to हिन्दी, check **🏦 Bank call** | "Answers in 12 languages, so it works for parents too." |
| 1:45–2:10 | **Screenshot** tab, drop a WhatsApp screenshot, tick consent, check | "Screenshots work too. Pictures can't be redacted, so they're sent to the cloud only with consent, and the receipt says so." |
| 2:10–2:30 | Turn on **Private only**, check again | "Private mode never uses the cloud: instant checks only." |
| 2:30–2:45 | WhatsApp Web with the extension's red banner (or the right-click menu) | "The Chrome extension warns you right inside Gmail and WhatsApp Web, scanning locally. Second Look: open source, private by design." |
